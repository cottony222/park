# 이지앤프리 담은 블랙 김치통 — 폴더링 / 썸네일 제작

`실행.bat`을 더블클릭하면 `D:\코워크\_누끼원본_추출\담은_김치통\` 아래에 아래 구조가 만들어집니다.
썸네일이 없는 상품은 `_단품누끼` 폴더의 누끼 이미지를 합성해서 1000x1000 썸네일(`*_썸네일_제작.jpg`)을 자동으로 만듭니다.
(Python 3와 `pip install pillow`가 필요합니다.)

```
담은_김치통\
├─ _단품누끼\                      ← 단품 누끼 PNG를 여기에 넣기 (파일명 규칙 아래)
├─ 01_원핸들_세트\
│   ├─ 3호_4종5P_1.4Lx2+2L+7.3L+13L\ {썸네일, 상세페이지}
│   ├─ 2호_3종4P_1.4Lx2+4.7L+8L\
│   └─ 1호_3종4P_1.4Lx2+2L+7.3L\
├─ 02_투핸들_1+1\  17L / 13L / 8L
├─ 03_원핸들_1+1\  7.3L / 6L / 4.7L / 4.3L / 2L / 1.4L_2P
├─ 04_투핸들_단품\ 17L_1P
└─ _작업현황.csv                   ← 상품별 썸네일/상세페이지 상태
```

## 단품 누끼 파일명

`원핸들_1.4L.png`, `원핸들_2L.png`, `원핸들_4.3L.png`, `원핸들_4.7L.png`, `원핸들_6L.png`, `원핸들_7.3L.png`,
`투핸들_8L.png`, `투핸들_13L.png`, `투핸들_17L.png` (png, webp, jpg 가능, 투명배경 권장)

## 참고

- 기존 썸네일(구글 드라이브나 쇼핑몰에서 받은 이미지)을 먼저 각 상품의 `썸네일\` 폴더에 넣고 실행하면, 그 상품은 새로 만들지 않고 건너뜁니다. 전부 새로 만들려면 `--force` 옵션을 붙이세요.
- 세트 상품(2호, 3호)의 8L/13L은 원핸들 누끼가 없으면 투핸들 누끼로 대신 만듭니다. 이 경우 `_작업현황.csv` 비고란에 표시됩니다.
- 상세페이지는 자동으로 수집하지 않습니다. 각 `상세페이지\` 폴더에 직접 넣어 주세요.

## 수집 현황 (2026-09-29, 클라우드 세션)

이 저장소의 `담은_김치통/` 폴더에 13개 상품 폴더(`썸네일/`, `상세페이지/`, `상품명.txt`)와 `_작업현황.csv`를 만들어 두었습니다.
**이미지는 아직 한 장도 들어있지 않습니다.** 작업 환경에서 세 소스 모두 접근이 막혔기 때문입니다.

실제 제품 사진이 없어서 썸네일도 만들지 않았습니다(AI로 제품 외형을 생성하지 않는다는 원칙).
합성 로직과 한글 폰트는 임시 도형 누끼로 테스트해서 정상 동작을 확인했습니다.

### 이어서 할 일
1. 받은 이미지를 각 상품의 `썸네일/`, `상세페이지/`에 넣기. 파일명 끝에 출처 표기: `…_드라이브.jpg`, `…_네이버_2.jpg`, `…_자사몰.jpg`
   (`_작업현황.csv`의 `썸네일_출처`/`상세페이지_출처` 열이 이 표기로 자동 집계됩니다)
2. 단품 누끼 PNG를 `_단품누끼/`에 넣기 (위 파일명 규칙). 누끼가 없으면 받은 사진에서 배경을 제거해 만들기 (예: `pip install rembg` 후 `rembg i in.jpg 원핸들_2L.png`)
3. `python make_dameun_thumbnails.py --root .` 실행 → 썸네일이 없는 상품만 `*_썸네일_제작.jpg` 생성, CSV 갱신
