# GPT 요청문: UI 시안 2장의 마스코트를 말랑 듀로 교체 (대외비)

## 함께 첨부할 이미지
1. UI 시안 A: `참고시안/필듀_시안_01_시작부터등록까지.webp`
2. UI 시안 B: `참고시안/필듀_시안_03_확인과관리.webp`
3. 말랑 듀 컷: 기본, 인사, 방패 컷(없으면 기본 컷과 수정 시안 `참고시안/필듀_마스코트_수정시안_말랑타임.webp`)

## 요청문 (복사해서 붙여넣기)

```
첨부한 앱 UI 시안 2장에서 마스코트만 새 캐릭터 "듀(말랑 듀)"로 교체해 주세요.
레이아웃, 문구, 아이콘, 색, 로고(필듀 PillDue)는 그대로 두고, 기존의 하얀 몽글 캐릭터만 바꿉니다.

[첨부 이미지]
- 시안 A: "01 시작부터 등록까지"
- 시안 B: "03 확인도 관리도 한눈에"
- 듀 마스코트 컷: 기본, 인사, 방패 등 (캐릭터를 새로 디자인하지 말고 첨부한 컷 그대로 사용)

[듀의 외형]
크림색 둥근 몸, 우유 피치색 테두리, 동그란 버튼 귀, 오른쪽 귀에만 시계 모양(시계에 숫자와 글자 없음), 짧은 팔다리, 작은 눈과 미소, 피치빛 볼.

[교체 위치]
시안 A
1. 브랜드 시작 화면: 로고 위의 캐릭터를 큰 듀로 교체 (정면 또는 인사 컷)
2. 오늘의 루틴: "오늘 3/8 완료" 카드 오른쪽의 작은 캐릭터를 눈웃음 듀로 교체
3. 사진으로 간편 등록, 등록 정보 확인: 마스코트 없음 (기존대로)
시안 B
1. 조합 확인, 성분 합계: 마스코트 없음 (기존대로)
2. 커뮤니티: 마스코트 없음. 광고 카드(브랜드 소식, 오늘의 브랜드 이야기)에는 절대 넣지 마세요
3. 마이: "내 정보는 내가 관리해요" 카드의 캐릭터를 작은 방패를 안은 듀로 교체 (방패에 십자가나 의료 표시 없음)

[반드시 지킬 규칙]
- 시계는 항상 오른쪽 귀에만 둔다
- 슬프거나 아픈, 졸린, 화난, 놀란 표정은 쓰지 않는다
- 약품 표기, 글자, 용량 숫자, 의사 가운, 청진기를 넣지 않고, 몸을 알약이나 캡슐 모양으로 바꾸지 않는다
- 듀가 효능을 말하거나 특정 제품을 가리키는 장면을 만들지 않는다
- 광고·스폰서 카드와 경고 카드(확인할 항목)에는 듀를 넣지 않는다
- 한글 문구는 오탈자 없이 기존 그대로 유지하고, 하단의 "디자인 시안·색상·제품·시간·수치는 예시입니다" 문구도 유지한다
- 이미지 비율과 해상도는 기존과 같게 한다

[출력]
수정한 시안 A, B 두 장, 그리고 바뀐 부분 목록을 글로 함께 알려 주세요.
```

## 선택 요청 (기획서 §34-5의 수정 필요 항목, 함께 반영할 때만 위 요청문 끝에 붙이기)

```
[추가 수정 요청]
1. 오늘 화면의 "내게 맞는 영양제" 카드를 "내게 필요한 성분"으로 바꾸고, 제품 사진과 제품명 없이 성분 이름만 보여 주세요.
2. 성분 합계 화면에 성분별 권장선과 상한선을 보여 주는 얇은 막대를 넣고, 상한을 넘으면 "상한 초과" 문구와 함께 차분한 색으로 표시해 주세요.
3. 섭취 시간 선택에 "기상 직후 공복"과 "취침 전"을 추가해 주세요. (기존 아침, 점심, 저녁, 직접 입력과 함께)
4. 경고 요약은 "확인 필요"와 "조정 권장" 두 등급으로 나누고, 색만 쓰지 말고 아이콘과 글자를 함께 써 주세요.
5. 메인 색을 지금의 코랄보다 한 단계 부드러운 우유 피치로 바꿔 주세요. 배경 카드는 #FFE0CC 계열, 버튼은 #F4A583 계열, 버튼 위 글자는 진한 갈색으로 해 주세요.
```

## 받은 뒤 점검
- 시계 귀가 오른쪽에만 있는가
- 금지 표정, 약품 표기, 알약 몸통이 없는가
- 광고 카드와 경고 카드에 듀가 없는가
- 한글 문구가 기존과 같은가
- 결과 이미지를 `참고시안/`에 저장하고 기획서 §34-5 표를 갱신한다
