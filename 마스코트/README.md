# 말랑 듀 컷 폴더 (대외비)

와이어프레임(`필듀_와이어프레임_v0.1.html`)이 이 폴더의 이미지를 자동으로 찾아 쓴다.
컷이 없으면 도형 스케치로 표시되고, 컷이 있으면 실제 이미지로 바뀐다.

## 파일 이름 규칙

`dew_<컷 이름>.webp` (png, jpg, jpeg, svg도 인식). 투명 배경 PNG나 WebP를 권장한다.

| 컷 이름 | 파일 이름 | 용도 | 쓰이는 화면 |
|---|---|---|---|
| 기본 미소 | `dew_basic.webp` | 기본 컷. **다른 컷이 없을 때 임시 대체로도 쓰임** | 알림 아이콘, 가이드 |
| 인사(눈웃음) | `dew_hello.webp` | 손 흔들며 등장 | 온보딩 |
| 신남·눈웃음 | `dew_happy.webp` | 진행 카드 | 홈 |
| 알림(시계 톡톡) | `dew_alarm.webp` | 섭취 시간 알림 | 가이드 |
| 섭취 완료 | `dew_done.webp` | 체크 도장, 하이파이브 | 섭취 완료 |
| 연속 기록 | `dew_streak.webp` | 연속 달성 | (추가 예정) |
| 빈 화면 | `dew_empty.webp` | 빈 기록 카드를 든 모습 | 빈 화면 |
| 쉬어가기 | `dew_rest.webp` | 평소 표정, 편안히 앉음 | (추가 예정) |
| 중립(경고용) | `dew_neutral.webp` | 경고·약물·임신·면책 화면 | 분석 결과, 임신 모드 |
| 방패(마이) | `dew_shield.webp` | 개인정보 안내 | 설정 |
| 앱 아이콘 | `dew_icon.webp` | 얼굴과 시계 귀 중심 | 아이콘 후보, 알림 |
| 스플래시 | `dew_splash.webp` | 시작 화면 | (추가 예정) |

## 파일 이름이 다를 때

이미지 이름을 바꾸기 어렵다면 와이어프레임 파일 하단 스크립트의 `CUT_FILES`에 직접 지정한다.

```js
var CUT_FILES = { basic: '마스코트/필듀_말랑듀_01.webp', alarm: '마스코트/필듀_말랑듀_05.webp' };
```

## 연결 확인

와이어프레임 상단의 **마스코트 컷 연결 현황**에 컷별로 ✓ 또는 ✗가 표시된다.
컷이 없는 자리는 기본 컷(`dew_basic`)으로 임시 대체되며 **노란 점선 테두리**가 붙는다.

## 컷 점검 기준 (기획서 §34-4)

- 시계는 **항상 오른쪽 귀**에 있고, 시계에 숫자나 글자가 없다
- 슬프거나 아픈 표정, 졸림, 화남, 놀람이 없다
- 약품 표기, 글자, 용량 숫자, 의사 가운, 청진기가 없다
- 몸을 알약·캡슐 모양으로 바꾸지 않았다
- 앱 아이콘은 작은 크기(약 60px 이하)에서도 시계 귀가 보인다
